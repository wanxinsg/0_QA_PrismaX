# Release Note Sprint 22 (June 20 – July 31, 2026)

## New Features & Improvements

- Updated Round 1 QA review rules for fairer consensus scoring.
- QA review now prioritizes uploads that already have the most reviews, helping reviews finish faster.
- Introduced the QA Leaderboard so validators can track rankings, progress, and points.
- Download quota is now shown clearly in the frontend: each plan tier caps how many episodes a user can add to My Data / download.
- Added a banner on the Upload Data tab to surface important upload guidance and updates.
- Upload Data now supports drag-and-drop, making it easier to select and submit robotics data files.
- Duplicate episode uploads are now automatically detected and rejected to protect dataset quality.
- Updated the Upload SDK to align with the latest upload requirements; the SDK Quick Start now also walks users through registering their robot and applying to become an Operator on the Account page.
- Improved the robotics data sample detail page with clearer multi-camera preview, metadata, and layout.
