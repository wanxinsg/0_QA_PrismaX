# Release Note Sprint 24 (August 18 – September 14, 2026)

## New Features & Improvements

- Published the new PrismaX marketing site with refreshed Events and Network visuals, a dynamic Latest blog section, and a Request Access flow for limited-release plans.
- Published the Brand Kit page with logos, colors, typography, and usage guidelines for consistent brand materials.
- Introduced On-Demand Data Orders so organization owners can request custom robotics data, track delivery progress, approve delivery, and access order data in My Data.
- Robotics Data is now available in beta: users can preview the catalog and apply for full access from the data console; approved applicants receive an email when access is granted.
- Operators can view assigned jobs on the Upload Dashboard and upload data for those jobs using the Upload SDK.
- The Upload SDK now supports downloading API packages with a Download API Key—pull MCAP and video assets for an entire package in one call.
- Relaxed episode upload validation thresholds, including wider camera FPS tolerance and joint-to-camera sync.
- Rejected episodes now show the related MCAP file name, making it easier to identify which file failed review.
- Relaxed left and right arm camera resolution for multi-view capture.
- Uploads can now include URDF files alongside robotics data.
